# Skill "Python + Web Scraping" (en español)

Skill en un único archivo de texto (`SKILL_python_scraping.txt`) para asistentes de IA: buenas prácticas de Python, web scraping (httpx, requests, BeautifulSoup, selectolax, Scrapy, Playwright) y elección/uso de librerías. Obliga a trabajar con un plan previo y a dar respuestas concretas y verificadas.

## Uso

- Claude Code: creá `~/.claude/skills/python-scraping-pro/SKILL.md` con el contenido del archivo (ya trae el encabezado `name`/`description`).
- Otros asistentes: pegá el archivo como instrucciones de sistema o contexto.

## Fuentes

La skill se armó leyendo estos repositorios (no se incluyen aquí; cada uno tiene su propia licencia): vinta/awesome-python, lorien/awesome-web-scraping, zedr/clean-code-python, encode/httpx, microsoft/playwright-python, realpython/python-guide, psf/requests, scrapy/scrapy, anthropics/skills y google/styleguide. Los fragmentos citados llevan su fuente entre corchetes dentro del archivo.
